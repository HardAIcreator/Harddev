Кнопка мини-приложения

У ботов слева внизу от поля «Сообщение» есть кнопка — название может отличаться. Через неё открывается само приложение.

Важно · 02

Режим для ПК

По ссылке: открыть → справа сверху меню → «Открыть в браузере» → три точки → «режим для ПК». Для части игр на телефоне режим ПК лучше не включать.
